# RPL Pemodelan UML - Retail Nusantara

Pemodelan UML untuk Sistem Retail Nusantara pada tugas Rekayasa Perangkat Lunak.

## Pemodelan

- Use Case Diagram
- Use Case Specification
- Activity Diagram

## Use Case Utama

Use case yang digunakan dalam pemodelan meliputi Login, Lihat Dashboard, Lihat Prediksi Penjualan, Atur Notifikasi Stok, Kelola Data Produk, Lihat Laporan Bulanan, dan Export Data.

## Activity Diagram

Activity Diagram dibuat untuk use case Lihat Prediksi Penjualan.
